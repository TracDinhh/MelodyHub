# MelodyHub - Phân loại chức năng

## Không cần đăng nhập (Public - Visitor)

| STT | Chức năng | Mô tả |
|-----|-----------|--------|
| 1 | Browse Songs | Duyệt danh sách bài hát |
| 2 | Search Songs | Tìm kiếm bài hát theo tên |
| 3 | Filter by Genre | Lọc bài hát theo thể loại |
| 4 | View Song Details | Xem chi tiết bài hát |
| 5 | Browse Artists | Duyệt danh sách nghệ sĩ |
| 6 | View Artist Profile | Xem trang cá nhân nghệ sĩ |
| 7 | View Artist Songs | Xem bài hát của nghệ sĩ |
| 8 | Register Account | Đăng ký tài khoản mới |
| 9 | Login | Đăng nhập |

## Cần đăng nhập (Authenticated - User)

| STT | Chức năng | Mô tả |
|-----|-----------|--------|
| 1 | View Profile | Xem thông tin cá nhân |
| 2 | Update Profile | Cập nhật thông tin cá nhân |
| 3 | Like Song | Thích bài hát |
| 4 | Unlike Song | Bỏ thích bài hát |
| 5 | Follow Artist | Theo dõi nghệ sĩ |
| 6 | Unfollow Artist | Bỏ theo dõi nghệ sĩ |
| 7 | Create Playlist | Tạo playlist mới |
| 8 | View Playlists | Xem danh sách playlist |
| 9 | Update Playlist | Cập nhật playlist |
| 10 | Delete Playlist | Xóa playlist |
| 11 | Add Song to Playlist | Thêm bài vào playlist |
| 12 | Remove Song from Playlist | Xóa bài khỏi playlist |
| 13 | View Listen History | Xem lịch sử nghe |
| 14 | Record Playback | Ghi nhận đã nghe |
| 15 | Clear Listen History | Xóa lịch sử nghe |
| 16 | Logout | Đăng xuất |
